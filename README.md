# jmcrm

园区客户信息管理系统 HTML 演示版。

演示地址：https://waynezhu1992.github.io/jmcrm/

## 内容

- 使用原系统前端页面、样式及控件。
- 客户新增、编辑、详情及客户审批，包含商品分类、货物温区、收货标准、收费类别和多门店配置。
- 客户详情默认展示首个“仓储服务配置”页签。
- “新客户”标签位于基本信息卡片右上角，创建后七天内展示。
- 工作台、线索、商机、合同和基础管理页面。

## 访问方式

公开演示无需登录，登录、注册及密码找回入口已移除。打开网站直接进入客户管理。

## 运行

本项目为静态前端，页面资源已内嵌于 index.html，使用 Hash 路由，可直接通过 GitHub Pages 访问。首次加载需要下载完整演示资源。

所有预置客户及业务记录均为合成演示数据。新增和修改内容仅保存在访问者当前浏览器的本地存储中，不会写入 GitHub，不连接实际业务后台或 WMS。不同浏览器及不同网站地址之间的数据不互通。

温区范围为演示参考配置，具体业务应按商品标签和仓储合同确认。WMS 同步数据结构为演示契约，不代表已接入实际系统。
