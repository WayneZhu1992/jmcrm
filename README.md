园区客户信息管理系统 HTML 演示版，当前需求版本 **v1.0.0**，无需登录。

**公网地址：https://waynezhu1992.github.io/jmcrm/**

- [v1.0.0 新需求说明](docs/PRD-v1.0.0.md)
- [版本日志](CHANGELOG.md)
- [v1.0.0 预览](https://waynezhu1992.github.io/jmcrm/versions/v1.0.0/)

缺陷修复继续沿用当前需求版本，记录修复日期和 Git 提交，不单独增加需求版本。

包含客户商品分类、温区、收货标准、收费类别、多门店、新客户标签及客户分配等演示功能。所有预置资料为合成数据，操作仅保存至当前浏览器，不连接真实业务后台或 WMS。
