# JMCRM v1.1.0 本轮修改说明

本轮仅修改用户指定的七项内容，原模块与原字段不做无关调整；本地版本仍为 v1.1.0。

## 本轮七项修改

1. 工作台移除“v1.1.0 权限与授权演示工具”，保留原工作台内容。
2. 恢复 v1.0.0 五项仓储服务配置在新增、编辑、详情中的红色标识，不改原字段内容及校验。
3. 协助跟进入口移至“跟进信息”，只有有效被指定业务员显示；复用原完整跟进表单，跟进人默认并锁定为该业务员。
4. 协助回款入口移至“回款”的“回款记录”类别，仅有效被指定业务员显示；复用原完整回款记录表单。
5. 删除独立的“v1.1.0 两级审批流程”重复模块，新增字段合并到原基本信息并标红，历史合并到原审批信息列表。
6. 恢复合同审批按钮与原审批操作页，分别校验审核权和资料编辑权，保留两级顺序及通过/拒绝操作。
7. 根组织、部门、分组按组织结构确定类型，分组只挂在末级部门下，修复旧表单造成的类型混淆。

## 按版本查看红色需求

完整 v1.0.0 需求见：v1.0.0-红色需求清单.md / v1.0.0-红色需求清单.html。

完整 v1.1.0 需求见：v1.1.0-红色需求清单.md / v1.1.0-红色需求清单.html。

两个版本新增需求均以红色显示。其余旧字段、原查询、列表、表单和操作保持原规范。最新演示已发布至原 GitHub Pages 地址，需求版本保持 v1.1.0。
