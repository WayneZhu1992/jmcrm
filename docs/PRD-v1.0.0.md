需求版本：**v1.0.0**。恢复分配客户下拉属于缺陷修复，不增加需求版本。

## 1. 新增字段

五组字段均为必填，标签标红，客户新增、编辑、详情同步展示。

| 字段 | 交互 | 规则与用途 |
| --- | --- | --- |
| 商品分类 | 可搜索、下拉多选 | 使用指定的18个分类编码；同名冷冻肉类按12、21分别保存。同步至WMS后，限制该客户商品可选分类。 |
| 货物温区 | 多选勾选 | 常温、恒温、冷冻、冷藏、超低温、自定义；展示温度范围；自定义配置名称及温度上下限，可增加多条。同步至WMS后限制商品维护和入库可选温区。 |
| 客户收货标准 | 按已选温区分别配置 | 每个温区设置温度条件、是否有湿度要求及湿度范围。WMS收货录入实测值后自动判定合格或异常。 |
| 客户收费类别 | 可搜索、下拉多选 | 使用指定的29个类别；不计费用与其他类别互斥。同步至WMS后限制客户可用费用类型。 |
| 客户门店 | 一对多 | 至少一个门店，支持增删。门店名称、省市区、详细地址必填；联系人、电话可选。同步至WMS客户信息模块展示。 |

## 3. 温区与收货规则

| 温区 | 演示参考范围 |
| --- | --- |
| 常温 | 10～30℃ |
| 恒温 | 15～25℃ |
| 冷冻 | -25～-18℃ |
| 冷藏 | 0～10℃ |
| 超低温 | -60～-40℃ |

上述温区范围是演示参考配置，不是对所有商品统一适用的强制标准；正式使用按商品标签、合同及库房条件确认。

- 自定义温区名称不可重复，最低温度必须小于最高温度。
- 每个所选温区生成独立收货规则，移除温区时移除对应规则。
- 温度支持低于、不高于、高于、不低于、区间内五种条件，明确是否包含边界。
- 湿度可选无要求，或设置0～100%RH内的相对湿度范围。
- 例如“冷冻低于-12℃”不含-12℃；如同时要求40～80%RH，温度和湿度都达标才合格。
- 缺少要求录入的实测值时，不直接判定合格。

## 5. 新客户标签

- 创建起七天（7×24小时）内展示，满七天后移除。
- 编辑不改变创建时间，也不延长有效期。
- 客户列表展示标签；详情标签放在基本信息卡片右上角。
- 数据结构提供isNewCustomer和newCustomerUntil，供WMS同步；页面不增加推送按钮。

## 6. 页面一致性

- 新增、编辑、详情中的配置一致，编辑可回填已保存数据。
- 仓储服务配置是详情第一个页签，位于跟进信息前并默认选中。
- 新客户标签不在仓储配置区重复展示。
