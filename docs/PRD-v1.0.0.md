## 3. 货物温区配置与客户选用

系统管理新增二级菜单「货物温区配置」，支持查看温区列表、新增和编辑温区。新增/编辑弹窗包含温区名称、温度标准、湿度要求和备注说明。温区名称必填且不可重复；温度标准沿用客户收货温度条件，支持区间内（含边界）、低于、不高于、高于、不低于。区间条件维护上下限，单阈值条件维护相应边界。湿度要求为无要求或有要求；选择有要求时维护湿度标准（0～100%RH，区间下限不得大于上限）。

系统内置常温 10～30℃、恒温 15～25℃、冷冻 -25～-18℃、冷藏 0～10℃、超低温 -60～-40℃五种参考温区。内置温区允许二次编辑，不提供删除操作。上述范围为演示初始值，具体业务标准按实际商品和仓储要求配置。

新增、编辑客户时，「货物温区」必填、多选，选项及温度/湿度标准来自系统温区配置，不再由客户表单直接维护温区范围。编辑客户展示其已选温区；客户详情展示保存时的温区标准。

## 4. 客户收货标准

对每个已选温区分别配置合格温度条件及合格范围。条件支持区间内（含边界）、低于、不高于、高于、不低于；单阈值条件采用相应的上限或下限。配置的达标温度范围必须落在所选温区的温度范围内，且两者交集须有效，不能出现无合格温度的空区间。

若所选温区配置为「有湿度要求」，客户收货标准需填写合格湿度范围，范围为 0～100%RH 且下限不大于上限；温区为「无要求」时客户表单不显示合格湿度输入项。变更已选温区后，系统为新增温区生成对应标准，并按温区配置校验已有标准。

WMS 收货环节录入实际温度及所需湿度后，根据客户保存的温区和收货标准自动判断商品为合格或异常；缺少规则要求的实测数据时不得判定为合格。WMS 对客户商品可选温区的限制取自 CRM 同步的客户温区配置。

## 6. 新客户标签

- 创建起七天（7×24小时）内展示，满七天后移除。
- 编辑不改变创建时间，也不延长有效期。
- 客户列表展示标签；详情标签放在基本信息卡片右上角。
- 数据结构提供isNewCustomer和newCustomerUntil，供WMS同步；页面不增加推送按钮。

## 7. 页面一致性

- 新增、编辑、详情中的配置一致，编辑可回填已保存数据。
- 仓储服务配置是详情第一个页签，位于跟进信息前并默认选中。
- 新客户标签不在仓储配置区重复展示。
