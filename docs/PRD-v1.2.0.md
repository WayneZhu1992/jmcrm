# v1.2.0 客户账单与回款

## 客户账单
客户详情新增“客户账单”。账单按客户和月份唯一，显示客户名称、账单月份、结算状态、本月应收账款、本月实收账款、未收款账款（历史）、最新更新时间。结算状态分为已确认（未结算）、部分结算、已结算。

提示：CRM支持每天零点定时从WMS拉取客户的账单数据，您也可以手动拉取。重复拉取更新同月账单，并追加操作日志，记录时间、方式、操作人、更新账单数和结果。“查看客户账单”提示正式环境将跳至 WMS 收费账单模块。静态演示模拟零点任务，关闭页面期间不运行后台任务，再次打开时补做当日同步。

## 回款统计
按当前客户汇总：回款计划总数及未回款、回款中、已完结、已作废各状态数量；计划回款总金额不含已作废；已回款总金额取有效回款记录的实际金额；已回款占比为已回款总金额除以计划回款总金额，保留两位小数，分母为零显示“—”；实收款金额按该客户各月账单的本月实收账款合计。

## 计划周期及状态
新增回款计划必须选择起止日期，可选择同一天。提前提醒规则针对周期的开始和结束日期；旧计划单一日期展示为同日起止。

新计划默认为未回款。关联第一笔回款记录后转为回款中；录入时选择完结该期计划即转为已完结。已完结或已作废的计划不再列入可选期数，提交时再次校验。普通回款和限时协助回款使用相同规则。

## v1.2.0 优化需求

### 菜单及回款展示
所有角色的前端菜单隐藏“线索管理”“客户审批”；创建或编辑角色时，权限树不展示这两个模块，保存时也剔除其权限键。回款 Tab 名称标红；回款计划列表在计划时间周期后增加延期状态，结束日早于当前日期且计划未完结/作废时标为“已延期”。回款计划和记录提供不同日期及状态的模拟数据。

## v1.2.0 新增需求

### 钉钉合同同步
合同录入列表提供“从钉钉同步合同”按钮，模拟拉取三条钉钉合同，默认草稿，可沿用原编辑和提交审批流程。同步记录保留钉钉合同审批单号。列表新增合同状态下拉筛选与合同来源字段（系统新增、钉钉同步）。不连接真实钉钉接口。

### 客户详情及合同录入优化
客户详情移除“合同信息”Tab。回款计划的“合同名称”为红色必填字段，选项限定为当前客户在合同录入模块中甲方为该客户且已审批通过的合同；保存时再次校验合同归属和审批状态。合同录入新增合同页面将甲方名称标注为红色“甲方（客户名称）”。合同状态筛选放在合同搜索区域；“从钉钉同步合同”按钮移至“新增合同”旁，采用白底红色边框样式。
