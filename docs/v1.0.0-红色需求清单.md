# v1.0.0 新需求清单（页面红色部分）

此清单只描述 v1.0.0 新增业务内容。原客户基础资料、证照、原列表及原业务功能保持原内容。以下新增字段在新增客户、编辑客户、客户详情中均使用红色标识。

## 1. 商品分类

必填，下拉多选。客户可选择的分类为：冷冻肉类（12）、冷鲜肉类（16）、冷冻食品（14）、海鲜水产（11）、粮油调味（17）、西式点心（15）、冷冻肉类（21）、酒水饮料（22）、餐厨日用（24）、蛋类（25）、蔬菜豆类（43）、其他（44）、干果（45）、冷冻饮品（雪糕/冰棍/甜味冰/食用冰）（46）、水果零食（47）、保健品（48）、佐餐（49）、谷物（50）。名称相同但编码不同的分类分别保留。

配置随客户资料同步至 WMS 后，该客户的商品分类仅能从已配置分类中选择。演示保留该接口口径和说明，不连接真实 WMS。

## 2. 货物温区配置与客户选用

系统管理增加二级菜单「货物温区配置」。管理员可查看列表、新增及编辑温区。弹窗包含温区名称、温度标准、湿度要求和备注说明。温区名称必填且不可重复；温度标准支持区间内（含边界）、低于、不高于、高于、不低于。湿度默认无要求，选择有要求后须维护 0～100%RH 的湿度标准，且下限不得大于上限。

系统内置常温 10～30℃、恒温 15～25℃、冷冻 -25～-18℃、冷藏 0～10℃、超低温 -60～-40℃，支持二次编辑，不支持删除。范围为演示初始参考值。

新增、编辑客户时，货物温区为必填多选，选项和温湿度标准来自系统配置。WMS 商品维护和入库仅能选择客户已配置的温区。

## 3. 客户收货标准

每个已选温区分别配置合格温度条件和达标范围，达标范围必须处于该温区温度标准内，且不能形成空范围。有湿度要求的温区才展示合格湿度范围，范围为 0～100%RH。WMS 收货录入实际温湿度后依据已保存规则自动判断合格或异常；缺少必要实测数据时不判为合格。

## 4. 客户收费类别

必填，下拉多选。保留原类别：仓储费、装卸费、抄码费、倒库费、缠膜费、出入库费、运费、装卸分拣费、急冻费、逨冻库装卸费、倒柜费（含人工）、单边装卸费（含人工）、倒柜费（不含人工）、換包装费（含装卸）、換包装（不含装卸）、单边装卸费（不含人工）、货转费、緩冻费、盖章费、清污费、覆盖粘胶费、托盘押金、卸货费、装货费、托盘卸货费、称重分拣、品控费用、贴标、不计费用。

WMS 业务计费仅能使用客户已配置的费用类型；“不计费用”不能与其他收费类别同时选择。

## 5. 客户门店

必填，一个客户可维护多个门店。每个门店维护名称、省市区、详细地址，以及联系人和电话；保留原必填与电话校验。

门店资料随客户同步至 WMS 客户信息管理模块，用于展示该客户的多个门店。

## 6. 新客户标签与详情展示

创建后七天内展示“新客户”状态标签，放在基本信息右上角；编辑不延长七天期限。接口状态按创建时间计算，不新增额外推送操作按钮。

客户详情以“仓储服务配置”为首个标签页，排在跟进信息之前。新增、编辑、详情展示同一套五项配置，保持原数据、字典、校验规则；本次恢复其红色需求标识。
