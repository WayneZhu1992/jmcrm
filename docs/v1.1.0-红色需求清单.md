# v1.1.0 新需求清单（页面红色部分）

以 v1.0.0 原页面为基线，只增补本版本需求。原筛选条件、列表字段、表单字段和其他业务功能保留；v1.0.0 与 v1.1.0 所有新增需求均用红色标识。当前需求版本保持 v1.1.0，已发布 GitHub Pages。

## 1. 客户转移

客户列表原“分配”改为红色“转移客户”，继续使用原组织用户选择弹窗。转移更新当前负责人，保留原创建人、创建时间及历史记录；撤销旧协助授权，并将待更新资料置为未推送。

## 2. 客户同步

新增红色“同步客户”入口，弹窗必填单选：推送客户，向 WMS 平台、联通客户小程序推送；拉取客户，从两平台拉取新客户。

确认后模拟同步。推送成功显示已推送，列表新增红色拉取状态。首次拉取模拟两平台各两条新客户，按来源与外部编号去重。管理员可管理全部客户，业务员及经理只能对可维护客户执行同步。不发生真实对接请求。

## 3. 角色及业务权限

业务员管理本人创建/负责的客户、线索、商机、合同及待办；组长查看本组数据，无他人业务编辑权限，负责组长首审；部门经理查看本部门数据，不操作其他人的业务资料，负责经理终审。

管理员保持原最大权限，可管理全部机构、账号、角色及全部业务数据；原角色创建、编辑和菜单授权保留。新增的数据范围、模块权限说明标红，审批节点处理权与业务资料编辑权分别判断。

## 4. 机构及账号归属

保留原左侧机构树、右侧列表和原列表字段、原操作。新增红色机构类别、部门经理、组长，以及账号所属部门、所属分组。

“荆门园区管理集团”为默认根组织；“冷链业务部、供应链业务部”为部门；“仓储一组、配送二组、商贸一组、综合二组”为分组。分组只能挂在末级部门下；已有机构类别按结构确定，不能因编辑表单残留而错归类。树节点筛选展示所选分支，列表明确展示根组织、部门、分组类型。

模拟组织保持两个部门，每个部门两个分组。第一部门配置陈经理、赵组长、周组长、张业务、王业务；第二部门无账号。另保留原管理员，共六个账号。

- 机构管理「创建机构」弹窗移除「部门经理」和「组长」字段。创建部门或分组时，负责人待分配。
- 账号管理先在左侧机构树选择节点，再点击「创建账号」。弹窗移除「所属部门」和「所属分组」下拉。「所属机构」回显创建时选中的节点，只读。切换归属需关闭弹窗后重选节点。
- 选择部门并创建「部门经理」角色账号后，系统将账号绑定为该部门经理。选择分组并创建「组长」角色账号后，系统将账号绑定为该组组长。业务员账号归属所选分组。管理员账号选择根机构或部门。节点与角色不匹配时提示重新选择。已有负责人的节点须先交接，避免覆盖原负责人。
- 创建账号时，选择根机构或部门节点不能选「组长」，选择分组节点不能选「部门经理」。不适用的角色置灰，提交时逐一校验所选角色。

## 5. 合同两级审批

业务员提交后依次由组长、部门经理审核。普通业务角色不能跳级，管理员保留全量处理权限。驳回需填写原因，修改重提后重新经过两级审核并保留轮次与历史。

合同查询、合同录入详情不再新增重复的“v1.1.0 两级审批流程”独立模块。新增的登记人、当前审核节点、当前审核人、审批轮次、待回款金额、组长审核与部门经理审核结果移入原基本信息并标红。

审批历史合并到原“审批信息”列表，保留原审批时间、审批人、结果、意见列，补充红色审核节点和审批轮次。恢复合同审批列表的审批按钮、原审批操作页、审批意见以及通过/拒绝操作。

## 6. 限时协助授权

客户所属业务员可指定其他业务员，分别授予新增跟进、回款记录权限，配置生效与截止时间。状态包括未生效、生效中、已到期、已撤销；同一人同一客户同一动作的重叠授权不能重复创建。

授权到期、撤销或客户转移后停止新增，提交时再次检查。协助权限不包含客户编辑、转移、同步、合同编辑、回款计划新增或删除记录。历史记录保留实际操作人与关联授权。

## 7. 协助新增跟进

按钮放在客户详情“跟进信息”模块。只有该客户在有效期内被指定、且获跟进权限的业务员显示红色“协助新增跟进”按钮。客户负责人和管理员保留原普通新增入口，不显示协助新增按钮。

协助弹窗直接复用原“新增跟进信息”表单，字段保持一致：跟进内容、跟进人、跟进时间、跟进方式、跟进状态、附件。跟进人默认并锁定为被指定业务员；原字典、附件和字段校验保留。保存后在原跟进列表展示。

## 8. 协助新增回款

按钮放在客户详情“回款”模块。仅有效被授权业务员切换到“回款记录”类别后，才显示红色“协助新增回款”；“回款计划”类别不显示。

协助弹窗直接复用原“新增回款记录”表单，字段保持一致：回款编号、客户名称、合同名称、负责人、回款计划期数、计划回款金额、回款金额、是否完结该期计划、回款日期、回款方式、备注。

仅可选择该客户已审批通过的合同；实际回款为正、最多两位小数，且不超过合同待回款额。计划金额与实际回款金额分别保存，不混用。保存后在原回款记录列表展示，保留实际协助录入人。

## 9. 工作台边界

去掉“v1.1.0 权限与授权演示工具”整个模块，保留原工作台统计、图表、日程及原待办。演示身份切换用于查看角色权限，不增加登录功能。
