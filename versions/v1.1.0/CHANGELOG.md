# v1.1.0 发布日志

## v1.1.0 — 权限、同步与限时协助

首次公网发布：2026-11-17。

### 新需求

1. 客户“分配”调整为红色“转移客户”，保留组织用户选择。
2. 模拟推送、拉取客户，展示推送状态及新增拉取状态，重复拉取去重。
3. 业务员、本组组长、部门经理的数据范围及权限；管理员保留最大权限。
4. 机构、账号保留左树右列表，补充部门、分组、经理、组长与账号归属。
5. 合同按组长初审、部门经理终审两级审批，支持驳回重提及审批历史。
6. 客户限时协助授权；指定业务员在有效期内使用原表单新增跟进、回款记录。
7. v1.0.0 与 v1.1.0 新增字段、入口均标红，保留既有业务内容。

详见 [v1.1.0 需求说明](docs/PRD-v1.1.0.md)。

### 缺陷修复与展示优化 — 2026-11-17

- 按业务员、组长、部门经理修正菜单与路由权限，管理员全菜单不变。
- 合同查询、合同录入、合同审批详情中的既有红色字段改为“合同录入 → 组长初审 → 部门经理终审”横向流程，窄屏横向滚动。
- 恢复原跟进、回款、审批表单，保留原机构和账号字段、原审批历史。
- 本节属于修复及展示优化，不列为新增需求，不提升需求版本。
